# Vehicle Service Center Management System 🚗

A console-based Vehicle Service Center Management System developed using C++. The system helps customers and service center staff manage appointments, vehicle service records, and service-related activities.

## Features

### Customer
- Customer registration and login
- View service records
- Schedule service appointments
- Cancel appointments
- Update personal information

### Staff
- Staff registration and login
- View appointment schedules
- Access vehicle service records
- Update service records
- Mark services as completed

## Technologies Used

- C++
- File Handling (TXT files)
- Code::Blocks IDE

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ridmi18/Vehicle-Management-System.git
   ```
2. Open the `Project` folder.
3. Open `UGC0323018.cpp` using Code::Blocks on Windows.
4. Click **Build and Run** to execute the program.

## Data Storage

The system uses text files to store customer details, staff information, appointments, and vehicle service records.
